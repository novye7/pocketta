# 0.7.0 交互重设计与验证

日期：2026-11-14。环境：macOS、ego-lite 的已安装扩展、agent-browser 的独立 Chromium。

## 本次修改

- `components.js` 区分 UI 组件与正文。表格使用内部 `<table>` 作为导出范围，相同边界的包装层合并；按回复标识和组件路径恢复被重新渲染的选择。
- `picker.js` 替代旧面板：浮动工具条、组件高亮、层级选择、上下切换、复制与下载、折叠选项、边界反馈、焦点恢复及减弱动态效果。长对话支持滚动寻找尚未加载的组件，搜索无结果时恢复位置。
- 保留 PNG / SVG、透明背景与文字轮廓，加入 PNG 3×。导出界面移除主题、画布、自定义配色和预设入口，保留底层渲染能力。
- 仅 SVG 构建矢量场景，避免 SVG 不支持的伪元素文字或变换阻断 PNG。SVG 限制提供「改用 PNG」，重试原来的复制或下载操作。
- 安装或更新时为已打开的 ChatGPT 页面补入悬停脚本，图标与快捷键也会确保识别模块已注入。扩展权限未增加。

## 收尾发现及修复

1. 悬停按钮的 `scale` 会缩放 `transform: translate(...)` 中的位移，出现动画期间偏离组件约 110px。改用独立 `translate`，以右上角为缩放原点，出现过程中的角落定位也通过检查。
2. 浮动工具条在窄窗口溢出。限制最大宽度、允许主控件行换行，并用实际行高定位；280px 下打开和关闭 PNG / SVG 选项均无控件越界。
3. 旧交互测试将边界反馈动画误判为选框恢复失败，且错误假定重新打开必定选择卡片 A。现在等待实际归位，并检查窗口中点处的表格。
4. 测试夹具位于 `<html>` 下，旧事件探针却挂在 `<body>`，未观察到夹具事件。改在 `document` 监听，确认组件点击被拦截，外部点击能关闭工具并传给页面。
5. 新增 `npm run test:browser`：独立命名浏览器、拦截测试页面请求、按序注入脚本、失败返回非零退出码，并在结束时关闭浏览器。无需依赖旧会话的临时脚本。
