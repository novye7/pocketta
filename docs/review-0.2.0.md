# 0.2.0 代码 review 与验证

日期：2026-11-05。环境：macOS、ego-lite / Chromium 156。

## 本次结果

弹窗与页面工具采用黑白、圆角、图标按钮，移除版本标签、常驻说明与页脚文案。范围按钮保留 title 和 aria-label。页面工具跟随页面浅色/深色主题；错误时才显示具体错误说明。

增加透明 PNG：省略页面背景填充，保留组件自身背景、色块、文本抗锯齿和边框。默认普通背景模式保持原行为。没有增加扩展权限。

## Review 发现及修复

1. 对实际导出的图片做棋盘格合成检查时，发现代码块工具图标丢失。原因是外部 SVG 图集的 `<use>` 引用不能在独立 SVG 图片中直接读取。现在按需读取图集、嵌入符号定义并重写引用，支持本地与嵌套的外部符号、保留 currentColor。对循环引用、过深引用、过大图集及不支持内容明确报错；嵌入节点去除事件属性。
2. 旧版导出器会被全局存在性检查直接复用，新背景参数无法生效。现在导出器与工具会话按版本判断，升级时替换旧实现并清理残留面板。同版本再次打开仍关闭面板。
3. 精简弹窗后，原有错误状态需要显式取消 hidden，已修复并验证。清晰度与透明开关在导出期间禁用。
4. 紧凑布局在窄窗口可能横向溢出。控制行支持换行，状态文字允许省略；280px 视口下全部控件仍位于面板内。
5. 清理过期错误标记；关闭工具时释放主题观察器；检查 package 与 manifest 版本一致。

## 范围限制

透明模式不会抠除组件自身的不透明底色。Canvas、视频和 iframe 等既有限制继续适用；依赖复杂 SVG 滤镜、外部样式和图片的图形仍可能需要单独适配。已打开的旧对话页可刷新后使用新版。
