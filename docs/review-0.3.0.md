# 0.3.0 代码 review 与验证

日期：2026-11-05。环境：macOS、ego-lite / Chromium 156。

## 本次修改

下载按钮左侧增加 PNG 图片图标和 SVG 节点图标，以互斥的 aria-pressed 状态选择格式，保留 title 和 aria-label。默认 PNG；切换 SVG 隐藏像素倍率，切回 PNG 恢复此前倍率。两种格式都支持透明或页面背景，导出期间禁止切换选项。

SVG 沿用现有样式固化与资源嵌入逻辑，直接生成 `image/svg+xml` Blob，无需经过 Canvas；加入 `viewBox` 保持固定布局的比例缩放。下载扩展名取自实际返回的格式。

## Review 处理

- 原来 SVG 仅在图片解码环境中使用；下载后可作为文档打开，其行为边界不同。现移除脚本、事件、链接动作、表单提交及 autofocus、SVG 动画、模板和媒体内容，使导出保持静态。
- 移除 `<picture>` 的候选 `<source>`，避免覆盖已经嵌入的当前图片。
- PNG 倍率和 Canvas 尺寸限制仅作用于 PNG；SVG 保留 DOM 节点上限，允许长于 Canvas 单边限制的组件。
- 检查格式切换、失败后的按钮状态恢复、重新选取时的选项保留、图标可访问名称以及窄窗口布局。
- 没有增加扩展权限。当前没有发现阻塞性问题。

## 保留的边界

SVG 使用 foreignObject 内嵌 HTML，不是纯路径/文字的 SVG。浏览器已实际验证；设计软件兼容性需要另测。网页字体依赖查看环境，原有位图不会变成矢量。透明模式保留组件自身色块。
