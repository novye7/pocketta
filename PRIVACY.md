# Pocketta 隐私政策 / Privacy Policy

生效日期 / Effective date: 2026-11-23

## 中文

Pocketta 是一款独立开发的浏览器扩展，可将 ChatGPT 回复中的智能 UI 组件导出为 PNG 或 SVG。

- **网页内容。** 扩展只在 `chatgpt.com` 上运行，并读取页面结构以识别可选组件。当你复制或下载时，扩展会在浏览器中处理所选组件的内容、样式和资源。导出结果可能包含该组件中显示的文字、图片、图表或表单内容。部分导出需要重新读取组件引用的图片或 SVG 图标，浏览器会向这些资源的原始地址发出请求。
- **本地设置。** 扩展使用浏览器的扩展本地存储保存所选格式、PNG 倍率、背景、SVG 文字选项及快捷键提示状态。设置保存在当前浏览器配置中，可通过卸载扩展清除。
- **导出与共享。** 只有你触发复制或下载时，扩展才会生成导出内容，并将结果放入系统剪贴板或通过浏览器保存。Pocketta 不会将网页内容、设置或导出结果上传给开发者或导出服务，也不发送遥测数据，不出售或分享用户数据。你可以自行清理剪贴板和下载文件。

隐私问题可通过 [Pocketta 的 GitHub Issues](https://github.com/novye7/pocketta/issues) 联系维护者。请勿在公开问题中附上私人对话或导出文件。

## English

Pocketta is an independently developed browser extension that exports Intelligent UI components in ChatGPT replies as PNG or SVG files.

- **Website content.** Pocketta runs only on `chatgpt.com` and reads page structure to identify selectable components. When you copy or download, it processes the selected component’s content, styles and resources in your browser. The export may include text, images, charts or form content displayed in that component. Some exports need to retrieve images or SVG icon resources referenced by the component. Your browser requests those resources from their original URLs.
- **Local preferences.** Pocketta uses the browser’s local extension storage to remember the selected format, PNG scale, background, SVG text option and shortcut hint state. These preferences are stored in the current browser profile. Uninstalling the extension clears them.
- **Export and sharing.** Pocketta generates exports when you choose to copy or download and writes the result to the system clipboard or saves it through the browser. Pocketta does not upload page content, preferences or exports to the developer or an export service. It does not send telemetry, sell user data or share user data. You can clear your clipboard and delete downloaded files yourself.

For privacy questions, reach the maintainer through [Pocketta’s GitHub Issues](https://github.com/novye7/pocketta/issues). Please keep private conversations and exported files out of public issues.
